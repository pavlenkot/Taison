# Пробный нативный проект

Это **скелет, а не приложение**. Задача одна: дать пощупать, как ощущается
нативный путь — прежде всего родной сканер и автоматическая запись в iCloud —
чтобы решение делать или не делать полноценное приложение опиралось на
ощущения, а не на описание.

## Что здесь есть

- **Родной сканер iOS** (`VNDocumentCameraViewController`) — тот самый, что в
  Заметках: сам ловит края, выравнивает перспективу, снимает несколько страниц
- **Сборка PDF** из отсканированных страниц
- **Запись в выбранную папку iCloud Drive** — выбираешь папку один раз,
  дальше приложение складывает туда PDF само, без диалогов
- **Разбор чека через AI** — Gemini или Claude, переключатель в настройках,
  та же схема и тот же промпт, что в веб-версии
- **Обязательная сверка человеком** — распознанное открывается в карточке,
  где всё можно поправить
- **Список расходов** с итогом за месяц, правкой и удалением

## Чего здесь нет

Намеренно: подписок, целей, задач, аналитики, синхронизации между устройствами,
экспорта. Всё это есть в веб-версии. Скелет проверяет ровно одну гипотезу —
стоит ли нативное того.

Данные лежат в обычном JSON в папке приложения. Не SwiftData и не CloudKit:
в пробнике важнее, чтобы проект открылся и запустился без единой настройки.

## Сборка

Нужен Mac с Xcode 15 или новее. Минимальная версия iOS — 17.

### Быстрый путь

```bash
brew install xcodegen
cd ios
xcodegen generate
open Taison.xcodeproj
```

### Путь без XcodeGen

1. Xcode → **File → New → Project** → **iOS** → **App**
2. Product Name: `Taison`, Interface: **SwiftUI**, Language: **Swift**
3. Сохрани проект в папку `ios/` этого репозитория
4. Удали созданные Xcode `ContentView.swift` и `TaisonApp.swift`
5. Перетащи в проект папку `ios/Taison` со всеми `.swift` файлами.
   В диалоге выбери **Create groups**
6. Выдели проект → target `Taison` → **Info** → добавь строку:

   | Ключ | Значение |
   |---|---|
   | `NSCameraUsageDescription` | `Камера потрібна, щоб сканувати чеки та документи` |

   **Без этого ключа приложение упадёт** при первом открытии сканера.
   Это не предупреждение, а гарантированный краш — iOS так защищает камеру.

7. Target → **General** → **Minimum Deployments** → iOS 17.0

### Запуск

**Только на настоящем iPhone.** В Симуляторе камеры нет, и сканер там не
запустится — это ограничение Симулятора, а не ошибка в коде.

1. Подключи iPhone кабелем
2. Xcode → target `Taison` → **Signing & Capabilities**
3. **Team** → выбери свой Apple ID (Add an Account, если его там нет)
4. **Bundle Identifier** поменяй на уникальный: `com.твояфамилия.taison`
5. Выбери свой iPhone в списке устройств сверху и нажми ▶

Первый запуск: iPhone → Настройки → Основные → VPN и управление устройством →
доверять своему сертификату разработчика.

## Про 7 дней

С **бесплатным** Apple ID подпись живёт **7 дней**, после чего приложение
перестаёт открываться, и его надо переустанавливать с Мака. Для пробника это
нормально — недели с головой хватит, чтобы понять ощущения.

Для ежедневного использования на четырёх устройствах нужен
**Apple Developer Program, $99 в год**: подпись живёт год, устройств до 100.

## Что проверить, пока щупаешь

1. **Сканер.** Наведи на мятый чек из кармана. Сравни с тем, как это делает
   веб-версия через обычную камеру. Разница здесь самая заметная.
2. **Папку iCloud.** Настройки → выбери `iCloud Drive/Чеки`. Отсканируй.
   Открой приложение Файлы — PDF должен лежать там. Проверь, что он виден
   с Мака.
3. **Скорость.** От нажатия до заполненной карточки. Сравни с вебом.
4. **Разбор.** Прогони 5–10 своих настоящих чеков. Смотри не на то, что
   распознано верно, а на то, **что распознано неверно** — это и есть цена
   решения. Сумма важнее всего: ошибка в магазине не страшна, ошибка в сумме
   портит статистику.

## Честно про качество этого кода

Я писал его без возможности собрать: здесь Linux, Xcode нет. Веб-версию я
собрал и прогнал, поэтому знаю, что она компилируется. Про этот код я такого
сказать не могу.

Скорее всего он соберётся — API, которые здесь используются, стабильные и
хорошо описанные. Но если Xcode ругнётся, пришли мне текст ошибки, и я
поправлю. Ошибки компиляции в Swift обычно чинятся одной строкой; страшно
не это, а если бы я стал уверять, что всё точно работает.

Отдельно: ключ API здесь лежит в `UserDefaults`. Для пробника на своём
устройстве это приемлемо, для настоящего приложения — Keychain. Менять
недолго, но в скелете это лишний слой между тобой и ответом на вопрос.
