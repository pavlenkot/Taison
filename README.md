# Taison

Личное приложение для учёта денег и дел: расходы, доходы, подписки и счета,
цели и ежедневные задачи. Со сканером чеков, который распознаёт сумму и
категорию через AI, и выгрузкой в таблицу — как банковская выписка.

Интерфейс на украинском, валюта — евро.

## Что умеет

**Гроші**
Расходы и доходы с категориями, датой, магазином и заметкой. Итоги за неделю,
месяц и год, сравнение с предыдущим периодом. Поиск по магазину и заметке,
фильтры по категории и типу, произвольный период — и выгрузка именно его.

**Підписки та платежі**
Регулярные подписки и разовые счета со сроком оплаты. На главной — список
«оплатить в ближайшее время», просроченное подсвечено. Нажатие «Оплачено»
создаёт расход, пишет платёж в архив и двигает дату следующего.

**Цілі**
Финансовые и обычные цели: сумма, дедлайн, пополнения, полоса прогресса.

**Щоденні завдання**
Список на сегодня с повторами (ежедневно, по будням, еженедельно).
Выполненное уходит в архив, повторяющееся само создаёт следующий экземпляр.

**Сканування**
Съёмка чека в приложении или Быстрая команда iOS с родным сканером.
AI читает магазин, дату, сумму и раскладывает по категориям — авто, продукты,
техника, кафе, рестораны, развлечения и так далее. **Всё распознанное можно
править** перед сохранением. PDF сохраняется в облако приложения, а Быстрая
команда кладёт его ещё и в папку iCloud Drive.

**Підсумок**
Отчёт за неделю или месяц человеческим языком: сколько потратил и как это
соотносится с прошлым периодом, самые крупные покупки, и — главное — сколько
незаметно набежало мелочью. Порог «мелочи» считается по медиане, то есть
«покупки дешевле X — это половина всех твоих операций», а не выдуманная цифра.
Когда мелочь перевешивает самую дорогую покупку, отчёт об этом говорит прямо.
Готовый отчёт за завершившийся период сам появляется на главной.

**Аналітика**
Столбцы расходов по дням или месяцам, разрез по категориям, сравнение периодов,
таблица с долями.

**Категорії**
Свои категории: добавить, переименовать, поменять значок и порядок. Ненужные
можно спрятать из списков, не удаляя — история остаётся целой.

**Скани**
Все чеки и документы одним списком с фильтром. Открываются по подписанной
ссылке, которая живёт минуту. Скан доступен и прямо из карточки операции.

**Архів**
Ничего не удаляется. Выполненные задачи, оплаченные платежи, закрытые цели —
всё лежит здесь и кормит статистику.

**Експорт**
XLSX с двумя листами (все операции + сводка по категориям) или CSV.
Расходы отрицательные, доходы положительные — открывается в Excel и Numbers
без плясок с кодировкой.

## Стек

| Слой | Чем сделано | Почему |
|---|---|---|
| Приложение | Next.js 15, React 19, Tailwind | PWA на все устройства без отдельных приложений |
| База | Supabase (Postgres) | Аналитика — один SQL-запрос, а не ручные счётчики |
| Вход | Supabase Auth, ссылка на почту | Без паролей |
| Файлы | Supabase Storage + iCloud Drive | Копия в приложении, оригинал у Apple |
| AI | Claude или Gemini, переключаются переменной | Не заперты в одном поставщике |
| Хостинг | Vercel | Бесплатно, деплой по пушу |

Доступ к данным закрыт на уровне базы (Row Level Security): каждая строка
привязана к владельцу, чужое не отдаётся даже при ошибке в коде приложения.

## Установка

Пошагово: **[docs/SETUP.md](docs/SETUP.md)**
Быстрая команда для сканирования в iCloud: **[docs/SHORTCUT.md](docs/SHORTCUT.md)**

Коротко:

```bash
npm install
cp .env.example .env.local   # впиши ключи Supabase и AI
npm run dev
```

Схему базы `supabase/schema.sql` нужно один раз выполнить в SQL Editor Supabase.

## Пробный нативный проект

В папке `ios/` лежит скелет SwiftUI-приложения — чтобы пощупать, как ощущается
нативный путь: родной сканер документов iOS и автоматическая запись PDF
в выбранную папку iCloud Drive. Это проба, а не замена веб-версии: подписок,
целей, задач и аналитики там нет.

Как собрать и что смотреть — **[ios/README.md](ios/README.md)**.

## Смена AI-движка

```
AI_PROVIDER=gemini   # или claude
```

Меняешь переменную в Vercel, жмёшь Redeploy. Остальной код о движке не знает —
за ним живёт общий контракт в `src/lib/ai/`.

Стоимость разбора одного чека — доли цента. $5 хватает примерно на 3800 чеков
на Gemini 2.5 Flash или на 1400 на Claude Haiku 4.5.

## Структура

```
src/
  app/
    page.tsx            обзор: итоги, платежи, задачи на сегодня
    transactions/       расходы и доходы
    subscriptions/      подписки и счета
    goals/              цели
    tasks/              ежедневные задачи
    digest/             отчёт за неделю и месяц
    analytics/          графики и сравнение периодов
    categories/         свои категории
    receipts/           все сканы и документы
    archive/            выполненное и оплаченное
    scan/               сканер и сверка распознанного
    actions.ts          все изменения данных
    api/
      scan/             распознавание из приложения
      ingest/           приём от Быстрой команды iOS
      export/           XLSX и CSV
      receipt/          подписанная ссылка на скан
  lib/
    ai/                 адаптер Claude ↔ Gemini
    digest.ts           расчёт отчёта и формулировки выводов
    supabase/           клиенты браузера, сервера и админа
  components/           интерфейс
supabase/schema.sql     таблицы, доступы, функции
```
