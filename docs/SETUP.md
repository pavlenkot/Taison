# Установка: от нуля до работающего приложения

Пройди шаги по порядку. Займёт примерно 30–40 минут, всё бесплатно
(кроме AI-ключа, где нужно положить минимум $5, которых хватит больше чем на год).

---

## Шаг 1. База данных — Supabase

1. Зайди на [supabase.com](https://supabase.com), зарегистрируйся, нажми **New project**.
2. Имя — `taison`. Регион выбери **Frankfurt (eu-central-1)** — ближе к тебе, быстрее.
3. Придумай пароль базы и **сохрани его** в менеджере паролей.
4. Дождись, пока проект развернётся (2–3 минуты).

### Создай таблицы

1. В левом меню открой **SQL Editor** → **New query**.
2. Открой файл `supabase/schema.sql` из этого репозитория, скопируй **целиком**.
3. Вставь в редактор и нажми **Run**.
4. Должно появиться `Success. No rows returned` — это правильный ответ.

Скрипт безопасно запускать повторно: он ничего не удаляет и не ломает.

### Забери ключи

**Settings → API**, оттуда понадобятся три значения:

| Что в панели Supabase | Куда вписать |
|---|---|
| Project URL | `NEXT_PUBLIC_SUPABASE_URL` |
| `anon` `public` | `NEXT_PUBLIC_SUPABASE_ANON_KEY` |
| `service_role` `secret` | `SUPABASE_SERVICE_ROLE_KEY` |

> `service_role` обходит все правила доступа. Он живёт только в переменных
> Vercel и нужен исключительно для приёма сканов от Быстрой команды.
> Никогда не вставляй его в код и никому не показывай.

## Шаг 2. AI-ключ

Возьми **один** из двух — или оба, чтобы потом сравнить на своих чеках.

### Gemini (дешевле)

1. [aistudio.google.com/apikey](https://aistudio.google.com/apikey) → **Create API key**.
2. **Обязательно включи оплату** (Set up billing) и привяжи карту.
   На бесплатном тарифе Google оставляет за собой право использовать твои
   запросы для улучшения своих продуктов, включая проверку людьми. Для чеков и
   личных документов это не годится. На платном тарифе данные для обучения
   не используются, а платить будешь центы.
3. Ключ → `GEMINI_API_KEY`.

### Claude (точнее на сложных чеках)

1. [console.anthropic.com](https://console.anthropic.com) → **API keys** → **Create key**.
2. **Billing** → пополни на $5.
3. Ключ → `ANTHROPIC_API_KEY`.

Данные API Anthropic для обучения не используются ни на каком тарифе.

### Переключатель

Переменная `AI_PROVIDER` — значение `gemini` или `claude`. Меняешь её в Vercel,
жмёшь Redeploy — приложение начинает разбирать чеки другим движком.
Остальной код об этом не знает.

Модель тоже настраивается:

- `GEMINI_MODEL` — по умолчанию `gemini-2.5-flash`
- `CLAUDE_MODEL` — по умолчанию `claude-opus-5` (самый точный).
  Хочешь дешевле примерно в 5 раз — поставь `claude-haiku-4-5`.

## Шаг 3. Токен для Быстрой команды

Придумай длинный случайный ключ. В Терминале на Mac:

```bash
openssl rand -hex 32
```

Скопируй вывод → `INGEST_TOKEN`.
И укажи свою почту → `INGEST_OWNER_EMAIL` (та же, которой будешь входить в приложение).

---

## Шаг 4. Деплой на Vercel

1. Залей репозиторий на GitHub, если его там ещё нет.
2. [vercel.com](https://vercel.com) → войди через GitHub → **Add New → Project**.
3. Выбери репозиторий. Framework Vercel определит сам (Next.js), настройки не трогай.
4. Разверни **Environment Variables** и добавь всё разом:

```
NEXT_PUBLIC_SUPABASE_URL      = https://xxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY = eyJhbGciOi...
SUPABASE_SERVICE_ROLE_KEY     = eyJhbGciOi...
AI_PROVIDER                   = gemini
GEMINI_API_KEY                = AIza...
INGEST_TOKEN                  = (вывод openssl)
INGEST_OWNER_EMAIL            = pavlenko.t@gmx.de
```

5. **Deploy**. Через пару минут получишь адрес вида `taison-xxxx.vercel.app`.

---

## Шаг 5. Разреши вход по ссылке

Supabase должен знать, куда возвращать человека после клика по письму.

**Supabase → Authentication → URL Configuration:**

- **Site URL**: `https://твой-адрес.vercel.app`
- **Redirect URLs**: добавь две строки:
  - `https://твой-адрес.vercel.app/auth/callback`
  - `http://localhost:3000/auth/callback` *(если будешь запускать локально)*

Теперь открой приложение, введи почту, получи письмо, нажми ссылку — ты внутри.
Категории на украинском создадутся автоматически при первом входе.

## Шаг 6. Поставь на все 4 устройства

Приложение — это PWA: ставится на домашний экран и выглядит как обычная программа,
без адресной строки браузера.

**iPhone и iPad**
Открой адрес в **Safari** (именно Safari — в Chrome на iOS это не работает) →
кнопка «Поделиться» → **На экран «Домой»**.

**Mac**
Safari → меню **Файл** → **Добавить в Dock**.
Или в Chrome: значок установки справа в адресной строке.

Данные общие: добавил расход с телефона — он сразу виден на Маке.

## Локальный запуск (необязательно)

```bash
npm install
cp .env.example .env.local   # впиши свои ключи
npm run dev
```

Открой `http://localhost:3000`.

## Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| Письмо для входа не приходит | Проверь папку «Спам». Бесплатный SMTP Supabase шлёт до 4 писем в час. |
| После клика по ссылке выкидывает на `/login` | В **URL Configuration** не добавлен адрес `/auth/callback`. |
| «Рушій не налаштовано» на странице сканирования | Нет ключа для движка, выбранного в `AI_PROVIDER`. Добавь ключ и сделай Redeploy. |
| Скан загрузился, но сумма 0,01 € | AI не разглядел итог. Открой карточку и впиши сумму — она для этого и открыта. |
| Пустые категории в списке | Схема выполнилась после того, как ты уже вошёл. Выполни в SQL Editor: `select public.seed_default_categories(auth.uid());` — или просто нажми Run на `schema.sql` ещё раз и перезайди. |
