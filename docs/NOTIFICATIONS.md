# Напоминания о сроках

Раз в день приложение присылает одно уведомление, если есть о чём:
срок в документе, платёж на подходе, задачи на сегодня. Если ничего не
горит — молчит. Уведомление, которое приходит каждый день без повода,
перестают читать на третий день.

Сторонних сервисов не нужно: веб-push работает на собственных ключах.

---

## Шаг 1. Сгенерируй ключи

В Терминале, в папке проекта:

```bash
node -e "console.log(require('web-push').generateVAPIDKeys())"
```

Получишь пару: `publicKey` и `privateKey`.

## Шаг 2. Пропиши переменные в Vercel

```
NEXT_PUBLIC_VAPID_PUBLIC_KEY = (publicKey из шага 1)
VAPID_PRIVATE_KEY            = (privateKey из шага 1)
VAPID_SUBJECT                = mailto:твоя@почта
```

`NEXT_PUBLIC_` в первой переменной обязателен: этот ключ по устройству
и так уходит в браузер, он не секретный. **`VAPID_PRIVATE_KEY` секретный** —
им подписываются уведомления от твоего имени.

`VAPID_SUBJECT` можно не задавать, если уже есть `INGEST_OWNER_EMAIL` —
тогда возьмётся он. Это требование протокола: push-сервису нужен адрес,
куда жаловаться, если приложение начнёт спамить.

После добавления — **Redeploy**.

## Шаг 3. Расписание рассылки

Рассылка живёт по адресу `/api/cron/reminders` и защищена тем же
`CRON_SECRET`, что и резервные копии. Добавь её в `vercel.json` рядом
с бэкапом — например, ежедневно в 6:00 UTC (8:00 по немецкому летнему
времени):

```json
{ "path": "/api/cron/reminders", "schedule": "0 6 * * *" }
```

Проверить вручную:

```bash
curl -H "Authorization: Bearer ТВОЙ_CRON_SECRET" \
  https://твой-адрес.vercel.app/api/cron/reminders
```

Ответ покажет, скольким отправлено и сколько промолчало.

## Шаг 4. Включи на устройстве

⚠️ **На iPhone и iPad уведомления работают только в приложении,
добавленном на экран «Домой».** Это ограничение Apple, обойти его нельзя.
В обычном Safari кнопка включения даже не появится — вместо неё будет
объяснение.

1. Открой приложение в Safari → «Поделиться» → **На экран «Домой»**
2. Запусти с домашнего экрана (не из Safari)
3. **Налаштування** → раздел «Нагадування» → **Увімкнути нагадування**
4. Разреши уведомления
5. Нажми **Надіслати перевірку** — должно прийти прямо сейчас

Шаг 5 не пропускай. Пока проверка не пришла, считай, что напоминания не
работают: слишком много мест, где это тихо ломается.

На Маке и Андроиде проще — работает и в обычном браузере.

---

## Если не приходит

| Симптом | Причина |
|---|---|
| Кнопки включения нет, вместо неё текст про экран «Домой» | Открыто в Safari, а не в установленном приложении |
| «Не налаштовано: бракує NEXT_PUBLIC_VAPID_PUBLIC_KEY» | Переменная не добавлена или не сделан Redeploy |
| Включил, но проверка не приходит | Уведомления запрещены в Настройках → Уведомления → Taskly |
| Приходило, потом перестало | Подписка устарела (бывает после обновления iOS). Выключи и включи заново |
| `Невірний токен` при ручном запуске | `CRON_SECRET` не совпадает или не передан заголовок |

## Почему офлайн ничего не показывает

Приложение намеренно **не кеширует страницы и данные**. Без связи
показывается «Немає зв'язку», а не сохранённый баланс.

Причина простая: устаревшие цифры хуже отсутствия цифр. Увидев вчерашний
остаток без пометки, легко принять его за сегодняшний. Кешируется только
оболочка — иконки и неизменяемая статика.
