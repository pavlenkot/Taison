# Быстрая команда: скан → iCloud → приложение

Это тот самый сценарий, который ты хотел: одно нажатие — родной сканер iOS
(с автообрезкой, как в Заметках), PDF автоматически ложится в папку iCloud Drive,
а копия улетает в приложение, где AI распознаёт сумму и категорию.

Веб-приложение само в iCloud Drive писать не может — у Apple нет такого API для
сторонних программ. Быстрые команды могут, поэтому запись в iCloud делает она.

---

## Подготовка

Создай в **iCloud Drive** две папки:

- `Чеки`
- `Документи`

Сделать это можно в приложении **Файлы** на iPhone или в Finder на Mac.

Держи под рукой два значения из настроек Vercel:

- адрес приложения — `https://твой-адрес.vercel.app`
- `INGEST_TOKEN`

---

## Сборка команды

Открой приложение **Команды** (Shortcuts) → **+** → назови `Сканувати чек`.

Добавляй действия по порядку. Названия даю по-английски и по-русски —
подставь те, что видишь у себя.

### 1. Scan Document · «Сканировать документ»

Ничего настраивать не нужно. Это и есть родной сканер с автообрезкой.

### 2. Make PDF · «Создать PDF»

Вход — результат сканирования. Оставь как есть.

### 3. Save File · «Сохранить файл»

- Вход: **PDF** из предыдущего шага
- Хранилище: **iCloud Drive**
- Папка: **Чеки**
- **Ask Where to Save** / «Спрашивать, куда сохранить» — **выключи**,
  иначе будет спрашивать каждый раз
- Включи **Overwrite If File Exists** — нет, оставь выключенным

### 4. Get Contents of URL · «Получить содержимое URL»

Разверни стрелку **Show More** / «Показать ещё»:

| Поле | Значение |
|---|---|
| URL | `https://твой-адрес.vercel.app/api/ingest` |
| Method / Метод | `POST` |
| Headers / Заголовки | ключ `X-Ingest-Token`, значение — твой `INGEST_TOKEN` |
| Request Body / Тело запроса | **Form** |

В теле запроса добавь два поля:

| Ключ | Тип | Значение |
|---|---|---|
| `file` | **File** / «Файл» | PDF из шага 2 |
| `icloud_path` | Text / «Текст» | `Чеки` |

> Важно: в поле `file` подставь именно PDF из шага «Создать PDF»,
> а не результат шага «Сохранить файл».

### 5. Get Dictionary Value · «Получить значение из словаря»

- Ключ: `message`
- Источник: результат шага 4

### 6. Show Notification · «Показать уведомление»

Текст — значение из шага 5. Так ты сразу увидишь
`ALDI · 23.47 € · чекає на перевірку`, не открывая приложение.

## Вторая команда — для документов

Продублируй готовую команду (долгое нажатие → **Duplicate**), назови
`Сканувати документ` и поменяй в ней два места:

- шаг **Save File** — папка `Документи`
- поле `icloud_path` — значение `Документи`

Приложение само разберётся, чек это или документ: договор или страховой полис
оно не запишет в расходы, а просто сохранит файл с коротким описанием.

---

## Куда повесить запуск

Чтобы не искать команду каждый раз:

- **На экран «Домой»** — в команде: «Поделиться» → «На экран Домой».
  Получится иконка, как у обычного приложения.
- **Кнопка действия** (iPhone 15 Pro и новее) — Настройки → Кнопка действия →
  Быстрая команда.
- **Постукивание по крышке** — Настройки → Универсальный доступ → Касание →
  Касание задней панели → Двойное касание → выбери команду.
- **Виджет** на экране «Домой» или на экране блокировки.

## Что происходит после нажатия

1. Открывается сканер, ты наводишь на чек — рамка ловится сама.
2. PDF сохраняется в `iCloud Drive/Чеки/`. Он твой, лежит в облаке Apple,
   доступен с любого устройства и никуда не денется, даже если снести приложение.
3. Копия уходит в приложение, AI читает магазин, дату, сумму и подбирает категорию.
4. Расход создаётся с пометкой **«чекає на перевірку»**.
5. Уведомление показывает, что распозналось.
6. Открываешь приложение → вкладка **Скан** → сверяешь и жмёшь «Підтвердити».

Проверка сделана нарочно обязательной: AI хорошо читает чеки, но не идеально,
а это твои деньги. Все поля в карточке открыты для правки — сумма, дата,
магазин, категория, заметка.

## Если не работает

| Симптом | Причина |
|---|---|
| `Невірний токен` | `INGEST_TOKEN` в команде и в Vercel не совпадают. Частая причина — пробел в конце при копировании. |
| `Користувача не знайдено` | Ты ещё ни разу не входил в приложение с почтой из `INGEST_OWNER_EMAIL`. Войди — и повтори. |
| `Приймання сканів не налаштоване` | В Vercel не заданы `INGEST_TOKEN` или `INGEST_OWNER_EMAIL`. Добавь и сделай Redeploy. |
| Ошибка 413 | PDF слишком большой. В шаге «Создать PDF» уменьши качество, либо сканируй по одной странице. |
| Уведомление пустое | Шаг 5 не нашёл ключ `message` — проверь, что источник именно результат шага 4. |
